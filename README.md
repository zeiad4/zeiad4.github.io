# Zeiad Khafagy's academic website

A small, responsive academic website for GitHub Pages. The page uses plain HTML and CSS, with no package installation, build step, or JavaScript required.

## Open locally

Open `index.html` in a web browser. The CV link uses the included `assets/Zeiad_Khafagy_CV.pdf` file. Public profile and paper links require internet access.

## Publish at zeiad4.github.io

1. Sign in to GitHub as `zeiad4`.
2. Create a public repository named **zeiad4.github.io**. If it already exists, review its current contents before replacing anything.
3. Upload the contents of this folder to the repository root: `index.html`, `assets/`, `.nojekyll`, and this README. Upload the files inside the extracted folder, not the ZIP itself or an extra enclosing folder.
4. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/ (root)**, then save.
5. Wait for GitHub's Pages deployment to complete, then open `https://zeiad4.github.io/`.

Official setup instructions: https://docs.github.com/en/pages/quickstart

## Edit the website

- Update the biography, research, publications, and education directly in `index.html`.
- The CSS is in the `<style>` block at the top of the same file.
- Replace `assets/Zeiad_Khafagy_CV.pdf` to update the downloadable CV while keeping the same link.
- Update the footer's last-updated date when making substantive changes.
- Add a photo later with descriptive alternative text and a responsive width. There is no placeholder portrait or empty space in the current layout.
- Add project code links only when a public repository for that specific project is available.
